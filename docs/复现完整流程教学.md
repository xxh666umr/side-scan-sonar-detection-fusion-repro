# 侧扫声呐目标检测：完整复现流程教学（从零到结果）

> 目标：让另一个人（或你自己过几周后）能照着这份文档，从零把整套实验跑出来。
> 本文对应桌面文件夹 `侧扫声呐融合复现` 里的工程；命令默认在 `repro\KD-YOLOX-ViT-main` 目录下执行。

---

## 0. 先搞清楚要复现什么

| 环节 | 内容 |
|---|---|
| 数据 | SWDD 侧扫声呐数据集（604 训练 / 130 验证 / 130 测试，2 类） |
| 模型 | YOLOX-Nano-ViT（参数量 0.96M） |
| 融合方案 | E0 基线 → E1 +KD → E2 +域自适应 → E3 +对抗重训练 |
| 指标 | test split：mAP@0.5、mAP@0.5:0.95、P/R；视频帧：AP50（OD-Metrics） |
| 产出 | `YOLOX_outputs/` 下的权重、`outputs/` 下的预测与指标 json、对比表 |

**最短路径（只看结果）**：不训练，直接用桌面包里的模型权重 + 评估脚本，30 分钟。
**完整路径（自己训练）**：从环境开始，约 1–2 天（单卡 8GB）。

## 1. 硬件/软件前置

- Windows 10/11 或 Linux，NVIDIA 显卡（≥8GB 显存；4GB 需把 batch 降到 4）
- 磁盘：至少 20GB 空闲（数据 3GB + 环境 5GB + 权重/输出 5GB + 余量）
- 网络：能访问 GitHub、PyPI、Zenodo（国内直连 Zenodo 很慢，见第 4 节技巧）
- Python 3.10–3.12（推荐 3.12；3.13+ 可能没有对应 torch 轮子）

## 4. 获取数据（SWDD）

官方地址：Zenodo 记录 10528135，整包 3GB（含 2.2GB 视频帧）。
论文训练只需要其中的 `Dataset/` 目录（约 692MB）。

### 4.1 方式 A：整包下载（简单但慢）

```powershell
curl -L -o SWDD.zip "https://zenodo.org/api/records/10528135/files/SWDD%20-%20Dataset.zip/content"
```

国内直连约 0.05–0.3 MB/s，3GB 要数小时。

### 4.2 方式 B：只下核心数据（推荐，约 0.5–1 小时）

用工程里的两个脚本：
1. `remote_zip_list.py`：远程读 ZIP 目录，生成 `data/swdd_entries.txt`
2. `fetch_entries.py annotations`：先下 3 个标注 json（很小）
3. `download_slice_parallel.py` + `extract_slice.py`：并行下载 `Dataset/` 的连续字节区间并解压

> 这套脚本是我们为“ Zenodo 限速”写的，思路：用 HTTP Range 只取需要的字节，不解压整包。
> 命令里的绝对路径按你的目录改一下即可。

### 4.3 目录结构（解压后必须长这样）

```
datasets/COCO/SWDD/
  train2017/   604 张 png
  val2017/     130 张
  test2017/    130 张
  annotations/
    instances_train2017.json
    instances_val2017.json
    instances_test2017.json
```

校验：`Get-ChildItem datasets/COCO/SWDD/train2017 | Measure-Object` 应为 604。
标注里 `categories` 应为 wall / noWall 两类。

> Windows 小技巧：数据放别处时，可 `mklink /J datasets\COCO\SWDD D:\data\SWDD` 建目录联接。

## 6. 第一步：先跑通评估（不训练，10 分钟）

变量准备（每次开新终端都要设）：

```powershell
$env:PYTHONPATH = "D:\你的路径\KD-YOLOX-ViT"
$env:TMP = "D:\你的路径\tmp3"; $env:TEMP = $env:TMP
```

评估官方 Nano 权重：

```powershell
python tools\fusion_eval.py -f exps\swdd\nano.py `
  -c "..\weights\swdd-nano.pth" `
  --data_dir "datasets\COCO\SWDD" `
  --ann "datasets\COCO\SWDD\annotations\instances_test2017.json" `
  --img_dir "datasets\COCO\SWDD\test2017" --tsize 416 `
  --out "..\outputs\pred_nano_test.json"
```

**期望结果**：`mAP@0.5 ≈ 0.155，Recall@0.5 ≈ 0.71`。
Nano-ViT 权重换成 `swdd-nano-ViT.pth` + `exps\swdd\nano_vit.py`，期望 `mAP@0.5 ≈ 0.227`。

> 如果这一步结果对得上，说明环境、数据、代码都正确，再往下训练。

## 7. 训练 E0 基线（约 2 小时 / 200 epoch，RTX 4060）

```powershell
python tools\train.py -f exps\swdd\nano_vit.py -b 8 --fp16 -expn e0 `
  -o data_num_workers 0 max_epoch 200 no_aug_epochs 10 eval_interval 10
```

参数含义：
- `-b 8` batch size（显存不足改 4）
- `--fp16` 混合精度（更快更省显存）
- `-expn e0` 实验名，权重存到 `YOLOX_outputs/e0/`
- `data_num_workers 0` 受限 Windows 环境必须；正常电脑可用 4
- `max_epoch 200` 论文用 300；赶时间用 120–200
- `no_aug_epochs 10` 最后 10 个 epoch 关闭强增强收尾

训练过程看 `YOLOX_outputs/e0/train_log.txt`，每个 `eval_interval` 会打印 val 的 AP。
产出：`YOLOX_outputs/e0/best_ckpt.pth`（按 val AP 选最好）。

## 8. 融合流水线 E1 → E2 → E3（一键或分步）

### 8.1 一键跑（推荐先这样，理解后再拆）

```powershell
python ..\run_pipeline.py --e0_ckpt "YOLOX_outputs\e0\best_ckpt.pth" --epochs 20
```

它会依次完成：
1. 教师 L-ViT 在源域生成伪标签 → 合并训练集 → 训练 **E1（+KD）**
2. 学生在“模拟目标域”生成伪标签 → 合并 → 训练 **E2（+DA）**
3. 用 E2 生成 PGD 对抗样本 → 合并 → 训练 **E3（+Robust）**
4. 对 E0/E1/E2/E3 分别在清洁/域偏移/PGD 三套测试上评估，写 `outputs/results.md`

### 8.2 分步命令（理解每一步在干什么）

```powershell
# 1) 教师伪标签（源域 604 张）
python tools\fusion_predict.py -f exps\swdd\l_vit.py -c ..\weights\swdd-L-ViT.pth `
  --img_dir datasets\COCO\SWDD\train2017 `
  --ann datasets\COCO\SWDD\annotations\instances_train2017.json `
  --out ..\outputs\pseudo_teacher_train.json --conf 0.5 --tsize 640

# 2) 合并“源域 GT + 教师伪标签”
python tools\fusion_merge.py --out_dir datasets\COCO\SWDD_kd `
  --out_ann datasets\COCO\SWDD_kd\annotations\instances_train2017.json --link --src `
  datasets\COCO\SWDD\annotations\instances_train2017.json datasets\COCO\SWDD\train2017 gt `
  ..\outputs\pseudo_teacher_train.json datasets\COCO\SWDD\train2017 kdt

# 3) 训练 E1（从 E0 初始化）
python tools\train.py -f exps\swdd\nano_vit.py -b 8 --fp16 -expn e1_kd -c YOLOX_outputs\e0\best_ckpt.pth `
  -o data_num_workers 0 max_epoch 20 no_aug_epochs 5 eval_interval 5 data_dir datasets\COCO\SWDD_kd

# 4) 目标域伪标签（先造模拟目标域：噪声/模糊/黑线/光照）
python tools\fusion_make_target.py
python tools\fusion_predict.py -f exps\swdd\nano_vit.py -c YOLOX_outputs\e1_kd\best_ckpt.pth `
  --img_dir ..\data\SWDD_domain\target2017 `
  --ann ..\data\SWDD_domain\annotations\instances_target2017.json `
  --out ..\outputs\pseudo_student_target.json --conf 0.4 --tsize 416

# 5) 合并后训练 E2，再用 E2 生成 PGD 对抗样本并训练 E3
#    （命令与上面同构，直接跑 run_pipeline.py 的 da/adv 阶段最省事）
```

> 说明：E1/E2/E3 每步只训 20 epoch（微调），这是为了在单卡上快速做消融；
> 要更接近论文可加到 100+，时间线性增加。

## 11. 常见问题（都踩过）

| 现象 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: yolox` | 没设 PYTHONPATH | 设 `PYTHONPATH=仓库绝对路径`，或在仓库根目录 `pip install -e .` |
| 日志 setup_logger 报 PermissionError / 命名管道 | 受限账户 | 把 `yolox/utils/logger.py` 的 `enqueue=True` 改 False |
| DataLoader 报 WinError 5 | 多进程命名管道被禁 | 加 `-o data_num_workers 0` |
| 评估报 torch_extensions 权限 | fast_cocoeval 要编译 C++ 扩展 | 把 `yolox/evaluators/coco_evaluator.py` 里 fast eval 改回 pycocotools |
| 显存不足 OOM | batch 太大 | `-b 4` 或 `-b 2`，或把 `input_size` 调小 |
| numpy 版本冲突 | opencv 装上了 numpy 2.x | 重新 `pip install numpy==1.26.4` |
| Zenodo 下载几 KB/s | 国际链路限速 | 用第 4.2 节选择性下载 / 香港节点 / 找国内镜像 |
| 评估结果 0 或 NaN | 大图没缩放对齐（视频帧 1570×390） | 用 `eval_video_modes.py` 的 640 letterbox 模式 |

## 14. 建议的复现顺序（照着做就行）

1. 环境装好，跑通 `fusion_eval.py` 评估官方权重 → 结果对得上再继续
2. 用桌面包里的权重直接看结果（不训练）
3. 想自己训：先 E0（200 epoch），看 val AP 是否到 0.2 左右
4. 再跑 `run_pipeline.py` 做 E1→E3 消融
5. 最后跑视频帧对齐（640），生成对比表
6. 把 `results.md`、`video_alignment.md`、PPT 更新成自己的数字
